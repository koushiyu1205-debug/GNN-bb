## Draft Activation Rule

Later drafting should proceed row by row. A row may be marked `PASS` only when:

1. its claim matches the claim register;
2. its evidence IDs point to the stated artifact class;
3. its citations have verified metadata and supporting passages;
4. its figure/table caption carries the same scope qualifier;
5. any `TBD` value has been replaced by a frozen artifact rather than an
   expectation;
6. it contains no first-person construction;
7. “exact,” “optimal,” “proved,” “proved” and “guaranteed” refer only to the
   exact path and fixed logical-path solution space.
