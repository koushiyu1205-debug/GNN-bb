# Evidence Bank

## Use Rules

1. `PROOF_CONTRACT` supports a mathematical or algorithmic guarantee only
   within its stated assumptions and implementation scope.
2. `EXACTNESS_IMPLEMENTATION` supports statements about proof ownership,
   fail-closed behavior, or implemented exact mechanisms; it is not a
   performance result.
3. `FROZEN_EXPERIMENT` supports measured claims within the frozen design.
4. `BENCHMARK_ONLY` and `DIAGNOSTIC` require those qualifiers in the sentence
   or its immediate context.
5. `HEURISTIC_DESIGN` describes an intended or scaffolded learning component;
   it cannot support effectiveness claims.
6. `MISSING_TBD` is an explicit evidence debt and must never be converted into
   an inferred value or conclusion.
